# datapack-for-server

**该数据包适用于Minecraft Java版1.16.2到1.16.5。不久后我便会更新1.17，尽请期待！**

## 功能列表
### 合成配方
我们在数据包中添加了一些合成配方，这些配方修正了原版的一些不合适的配方，也添加了一些玩家间迫切希望加入的配方。下面是列表：
#### 附魔金苹果
```
[工作台]
AAA    - A：金锭
AHA    - H：苹果    --> 附魔金苹果
ADA    - D：金块
```
```
[熔炉]
金苹果 -->(120秒)--> 附魔金苹果
```
```
[烟熏炉]
金苹果 -->(60秒)--> 附魔金苹果
```
```
[营火]
金苹果 -->(360秒)--> 附魔金苹果
```
#### 皮革
```
[工作台]
腐肉+腐肉    --> 皮革
```
```
[熔炉]
腐肉 -->(10秒)--> 皮革
```
